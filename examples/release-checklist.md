# 游戏发布检查表

这是使用团队开发游戏后的检查表，不是已执行的测试报告。

- [ ] 真实构建与启动命令已记录，依赖锁定。
- [ ] 最短完整玩家旅程已通过，保留截图、状态与错误记录。
- [ ] 桌面与移动输入、横竖屏、安全区域和音频限制已检查。
- [ ] 保存/读取、刷新、损坏存档与升级兼容已检查。
- [ ] 无密钥、私人数据或无授权素材进入发布目录。
- [ ] 素材、字体、音乐、引擎与第三方库许可已确认。
- [ ] 相对路径、大小写与仓库子路径部署已验证。
- [ ] 多人游戏已检查服务器权威、无效消息、掉线重连与清理。
- [ ] 已明确托管目标、公开范围、费用和用户授权。
- [ ] 有备份、版本标识和回滚方案。
- [ ] 部署完成后重新检查线上资源与玩家关键旅程。
- [ ] 报告实际访问地址、版本、测试证据和剩余风险。
