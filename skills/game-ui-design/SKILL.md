# Game UI Visual Designer

Make the interface look intentional and coherent with the game's art direction.

## Establish a UI system

Define:
- visual hierarchy
- spacing scale
- panel treatment
- button states
- typography hierarchy
- icon style
- selected/disabled/error states
- animation language
- contrast rules

## Game HUD

Show only information needed for the current decision. Keep critical game-world visibility clear. Avoid large opaque panels over important gameplay unless necessary.

## Pixel games

Respect pixel scale, nearest-neighbor rendering where appropriate, limited palette logic, crisp borders and consistent icon dimensions. Do not mix arbitrary modern UI styles with pixel art without a deliberate art-direction reason.

## Acceptance

Review desktop and mobile screenshots at representative sizes. Fix clipping, unreadable text, inconsistent spacing and accidental browser-default controls.
